# Editorial framework design

## Approved direction

Blend the Trionn-inspired editorial layout with the existing Northern Signal portfolio identity. Keep the current palette, type, aurora atmosphere, 3D scenes, and motion language.

## Structure

- Introduce a shared editorial rail: compact eyebrow/index, oversized statement, and supporting copy/action aligned on a consistent grid.
- Use the rail across Home, About, Work, and project content while preserving page-specific imagery and interaction.
- Rebuild the footer as a spacious collaboration CTA with contact, social, navigation, language, copyright, and back-to-top controls.
- Keep responsive and reduced-motion behavior explicit.
