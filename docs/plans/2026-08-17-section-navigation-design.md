# Section navigation and content hierarchy

## Approved scope

- Use one five-section sequence across the homepage: About, Projects, Expertise, Live Signal, and Contact.
- Keep the full hero navigation. Past the hero, show a compact header with the logo, a menu control, and the current contact action.
- The compact menu uses the existing navigation language and offers accessible anchor links, active-section feedback, outside-click closing, Escape closing, focus containment, and focus restoration.
- Norwegian is the content source of truth; English is a faithful translation.
- About copy is factual and personal. Project role/status labels are limited to current project data. The live-signal section is reduced in layout scale without changing its 3D aurora or KP functionality.
