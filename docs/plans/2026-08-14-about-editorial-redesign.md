# About page editorial redesign

## Design read

An editorial portfolio page for prospective clients and creative-agency hiring teams, using the homepage's northern field-station language: live aurora, oversized typography, utility metadata, asymmetrical grids, and restrained scroll-led motion.

## Structure

1. **About / 01** — coordinates, oversized personal introduction, supporting paragraph, and a separate design principle.
2. **Background / 02** — four chronological chapters presented as an editorial narrative rather than a résumé or capability list.
3. **Working method / 03** — pinned thesis beside progressing supporting copy, followed by the four-stage process line.
4. **Now / 04** — availability statement and email action.

## Visual system

- Reuse the homepage max-width, page gutters, dusty-pink type, pale aurora green, IBM utility labels, and Syne display type.
- Keep the live WebGL aurora visible beneath dark/translucent surfaces.
- Use hairline rules and sequence numbers only where order carries meaning.
- Remove the portrait placeholder and obsolete capability list.
- Treat the process line as the page's signature element.

## Motion

- Hero title uses the homepage blur-to-focus character reveal.
- Section headings and chapter content reveal through top-to-bottom clipping.
- Background chapters enter in reading order.
- Working-method thesis pins on larger screens while copy progresses.
- Process stages activate sequentially with scroll.
- Reduced-motion and compact layouts remove pinning and show content directly.

## Responsive behavior

- Desktop uses asymmetrical two-column compositions and one pinned section.
- Mobile collapses to a single reading column, preserves semantic sequence, and uses non-pinned reveals.

## Copy

- Norwegian text follows the supplied copy.
- English is adapted naturally while preserving the direct, plainspoken voice.
